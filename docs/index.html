Open source. Your machine, your keys, your tools.

The studio is Apache-2.0 and lives on GitHub. Clone it, run the whole thing on your own hardware, point it at your own ComfyUI, your own Ollama, your own GPU — and add a driver for the tool you wish existed. A pull request needs a real upstream link and a licence that a human actually read. It never needs your credentials.

git clone https://github.com/apex-architecture/sovereign-ai
cd sovereign-ai
npm install
npm run passport:selftest   # proves the browser signer and the server verifier agree
npm run dev                # the studio on your own machine

What a passport proves

An audit trail, never a claim of truth

A film passport proves that a statement was made, at a time, about exact bytes. It does not prove the film is true, authentic, original, authorised, good, or permanent. Anyone can check one for free — no account, no key, no payment — and that will never change.
