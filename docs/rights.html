— what each field lets you say

One row of the registry is a contract. The table below lists the rights fields in it, and the heading counts them from the data as the page loads. Each field answers a different question: can I use this for a paying client, can I ship it inside the platform, and can I claim rights over what it made. Those are separate questions and a licence answers only the first two. The final column of every row says so out loud.

The “recorded in the data” column is computed from the rows themselves at page load.

The rule that stops the work

An unread licence stops client work at the moment of use — not at invoice time, not at delivery.

  1. A run asks the registry for a tool.
  2. If that row's licence has not been read, the run is recorded as blocked, not forbidden: the answer is unknown.
  3. The job may continue on a row that is read and clear, or by hand, or with a written exit that replaces it.
  4. The block itself is sealed. A seal on a block is a receipt that we stopped — it says nothing about who was right.
