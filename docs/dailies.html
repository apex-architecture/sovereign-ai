waiting for the run sheet

Dailies

This page is not a pitch about what the platform will do. It is one run that already happened on a real machine, printed from runs/<stamp>/run.json by scripts/dailies-site.mjs. Every figure below — bytes, frames, seconds, mean luma — is read off that file or off a decoded frame, and none of them is typed in by a person.

The plates in this run were drawn for the demo. No client footage and no third-party asset ships on this rail. The run was admitted under personal use only — a machine-fetched licence text that names personal use permits that and nothing else. Client work and redistribution still require a human signature on the licence read.

The file it made

No web cut on this page — the run produced no master, or the assets were not generated.

How the road chose the engine

Before a single byte was rendered, the platform ranked every engine it knows for this stage against the machine actually under the run — its GPU, its keys, its territory, its budget. The refusals are printed because a shortlist without them is advertising. Rank your own shot on the Engine Road.

The gate table the picture was judged against

These are not our opinions about the shot. Each row is a limit taken from what a dailies review physically checks, measured on the master by ffmpeg inside the same run that made it, and printed with the number beside the limit. A red gate stays red on this page — the platform is allowed to fail in public, which is the only way a green one means anything.

Every stage, and the frame it produced

One frame out of each artefact, at the same second where the clip runs long enough to have one. The number under each picture is signalstats averaged over every frame of that file: YAVG is mean luma out of 255, SATAVG is mean chroma distance from grey. A stage that produced nothing has no picture — it is listed, not hidden.

The run sheet, stage by stage

The tried column is the fall-through chain runStage() actually walked, in order: licence gate → declared depth → reachability probe → the tool → next candidate. A stage that says refused is not a bug being hidden — it is the licence gate or a missing driver doing what it was built to do. The reason is the tool's own last line, copied unedited. The wall clock column is calendar time and nothing else: a run left going overnight on a machine that sleeps reports eleven thousand seconds for a render the GPU finished in three hundred and seventy-one. Where a tool measures itself, its own number is in the last column, because that is the one that predicts tomorrow's cost.

Proof the finishing pass changed pixels

Left is the cut before the finishing pass, right is the same second after it — lateral chromatic aberration, halation blooming off the highlights, gate weave, grain, the print curve, split tone and a measured corner falloff. The chain is finish in src/lib/apex/drivers/ffmpeg.ts, and each element was tuned against the frame it is meant to change.

Plate to shot

Left is the still plate as drawn. Right is what the motion stage handed back for the same shot. This is a camera move computed over a still, not a generated performance — the card in What this run does not prove says so plainly.

Two caption tracks, and what each one is for

The subtitles stage burned the lines into the frames, so the words below are part of the video stream and cannot be turned off. A burned line cannot be read by a screen reader, translated, or resized by a player, so the same lines also ship beside the file as WebVTT — the English track in the player above. The burn stays, because a delivery master that survives someone else re-encoding it is worth more than a clean frame.

What this run does not prove

No generative shot

The generative candidates for motion and storyboard stop at the licence gate on this machine: the recorded licence has not been read by a human, and the evidence lane only admits personal use. The moving image you watched is a camera move computed over a still. That is honest dailies, not a text-to-video result.

No voice, no score

dialogue has no driver at all — the stage is named and nothing is wired to it. music refused on an unread licence. The audio track is the normalised bed the mix stage laid down, not a performance.

Nothing was published

publish refused. The platform produced a file and stopped at its own edge; it did not post, email or spend on your behalf.

One door, one run

This is a single run of a single two-shot scene. It establishes that the pipeline can be walked end to end and can hand back a playable artefact with a printed ledger. It does not establish throughput, quality, or that any client work is cleared to ship.

Reproduce it

node --experimental-strip-types scripts/film-run.mjs <plate-1.jpg> <plate-2.jpg>
node scripts/dailies-site.mjs

The first command writes runs/<stamp>/ with every intermediate, the master and run.json. The second turns that run into this page's frames, measurements and web cut.
